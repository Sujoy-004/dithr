# Quick Plan: Modernized 16-Shader Visuals & Dynamic Stacking Architecture

## Task 1: Stacking Architecture & Pristine Ingestion Refactor
**Goal:** Implement clean media ingestion by default and intuitive instant stacking/unstacking UX in the studio store and LeftRail.

**Files:**
- `web/src/store/useStudioStore.ts`
- `web/src/components/layout/LeftRail.tsx`
- `web/src/components/panels/EffectInspector.tsx`
- `web/src/engine/registry/index.ts`
- `web/src/engine/registry/types.ts`
- `web/src/engine/graph/GraphCompiler.ts`

**Actions:**
1. Set `DEFAULT_INITIAL_STACK = []` in `useStudioStore.ts`. When media is loaded, the stack remains empty unless the user explicitly chooses a shader, giving pristine media passthrough.
2. In `engine/registry/index.ts`:
   - Register `'vhs'` alias to `crtVhsEffect` (or define `vhs` as canonical with `crtVhs` as alias) so that clicking `vhs` or `crtVhs` resolves the full VHS/CRT analog shader definition.
   - Expand `applyBlendMode` to support `normal`, `multiply`, `screen`, `add`, `overlay`, `softLight`.
3. In `LeftRail.tsx`:
   - Redesign the 16-shader grid into an intuitive, unified control center:
     - Each shader tile shows icon, name, and stack status (`In Stack` / `Bypassed` / unselected).
     - Clicking an inactive shader adds it to the active stack and selects it.
     - A quick `+` button on each card allows stacking additional passes.
     - Active shaders feature one-click remove (`Trash2`) and bypass toggle (`Eye`/`EyeOff`).
   - The Active Stack section at the top cleanly displays all stacked layers with reorder handles, layer badges, blend mode badge, and remove buttons.
   - When stack is empty, displays a clean status indicator showing media is in pristine passthrough mode.
4. In `EffectInspector.tsx`:
   - Add expanded blend modes (`overlay`, `softLight`) and clean compositing controls.

## Task 2: Modernize 16-Shader Visuals, UX & Compositions
**Goal:** Upgrade every single shader in `web/src/engine/registry/stylize/` and `modulate/` with modernized visual math, anti-aliasing, composition preservation, and aesthetic UX controls.

**Files:**
- `web/src/engine/registry/stylize/dither.ts`
- `web/src/engine/registry/stylize/halftone.ts`
- `web/src/engine/registry/stylize/ascii.ts`
- `web/src/engine/registry/stylize/dots.ts`
- `web/src/engine/registry/stylize/contour.ts`
- `web/src/engine/registry/stylize/pixelSort.ts`
- `web/src/engine/registry/stylize/blockify.ts`
- `web/src/engine/registry/stylize/threshold.ts`
- `web/src/engine/registry/stylize/edgeDetect.ts`
- `web/src/engine/registry/stylize/crosshatch.ts`
- `web/src/engine/registry/stylize/waveLines.ts`
- `web/src/engine/registry/stylize/noise.ts`
- `web/src/engine/registry/stylize/voronoi.ts`
- `web/src/engine/registry/stylize/matrix.ts`
- `web/src/engine/registry/stylize/tone.ts`
- `web/src/engine/registry/modulate/crtVhs.ts`

**Actions:**
1. `voronoi.ts`: Replace pseudo-spheres with true cellular Voronoi (Worley distance + cell edge borders + facet color sampling).
2. `waveLines.ts`: Replace black zebra multipliers with true analog oscilloscope sine wave raster line displacement and smooth line falloff.
3. `matrix.ts`: Add `sourceBlend` so falling digital code streams illuminate and composite over the user's footage instead of blacking out the screen.
4. `contour.ts`: Replace 90% blackout with stepped elevation posterization bands + anti-aliased isoline boundaries.
5. `dots.ts` & `halftone.ts`: Add `smoothstep` subpixel anti-aliasing to dot apertures, with paper tint and color preservation instead of pitch black voids.
6. `crosshatch.ts`: Implement 4-tier progressive hatching angles (45°, -45°, 90°, 0°) with smoothstep anti-aliasing.
7. `threshold.ts`: Add `softness` feathering parameter and duotone color remapping.
8. `dither.ts`: Support 8x8 & 4x4 Bayer matrices with gamma-correct luminance preservation.
9. `pixelSort.ts`: Upgrade scanline interval sorting for silky streaks.
10. `vhs` (`crtVhs.ts`): Refine tape jitter, scanline curvature, chromatic aberration, and phosphor bloom compositing.
11. Update other shaders (`ascii`, `blockify`, `edgeDetect`, `noise`, `tone`) to ensure sound parameter typing and zero-recompile uniform updates.

**Verify:**
`cd web && npm run test:unit -- src/tests/spatialShaders.test.ts src/tests/graphCompiler.test.ts`
