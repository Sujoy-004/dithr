# Quick Plan 261127-dg8: Transform `dithr.pages.dev/studio/` with Grainrad UI/UX, Functionality & Behavior (REA-Derived)

## Objective
Transform `web/` (deployed to `https://dithr.pages.dev/studio/`) using everything captured from `https://grainrad.com/` via REA — Grainrad's terminal typography (`IBM Plex Mono` / `JetBrains Mono`), 4 switchable themes (`default`, `vt320`, `cassette`, `coldwar`) + `light`, hairline sliders with quick `reset`, 10 ASCII character sets, retro palettes (`GameBoy`, `CGA`, `NES`, `PICO-8`, `C64`, `Apple II`, `Macintosh`, `Sepia`, `Cyberpunk`, `Newspaper`, `Risograph`), built-in + custom JSON Presets, global `+ Processing` & `+ Post-Processing` GPU chains, `Sharpness`, `Three.js .html` standalone 3D export, fullscreen/webcam/theme viewport toolbar, zoom/pan shortcuts, and About/Changelog modals — while **preserving** `dithr`'s media-first passthrough (`activeStack: []`), composable multi-pass stacking (`+ Stack`, reorder, bypass, `Clear all`), Audio Reactivity, and 3D Scene.
