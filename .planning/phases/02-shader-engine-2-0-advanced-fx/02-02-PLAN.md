    - Implement `planExecutionStages(stack: ActiveEffectPass[], registry: EffectRegistry)`:
      - Iterate through active enabled passes.
      - Accumulate contiguous pointwise passes into `FusedFragmentStage`.
      - When a pass with `requiresPass === true` or a generator pass is encountered, create an `IntermediateTargetStage` backed by `PassPool`.
    - Implement `compileGraph(sourceNode: any, stages: ExecutionStage[], uniformsMap: Map<string, any>): CompiledPipeline`:
