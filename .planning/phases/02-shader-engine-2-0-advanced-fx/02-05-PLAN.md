    - Partitions 128 bins into 3 bands: Bass (bins 0-2, ~0-375Hz), Mid (bins 3-14, ~560-2600Hz), Treble (bins 15-63, ~2.8-11.8kHz) per D-12
    - Asymmetric attack/release envelope filter implements fast attack (~20ms) and slower release (~200ms) per D-14
    - Output band energies scale with `sensitivity` slider [0.1, 3.0] and clamp to [0.0, 1.0]
    - Exposes per-band tuning overrides (bassAttack, bassRelease, midAttack, midRelease, trebleAttack, trebleRelease)
  </acceptance_criteria>
  <action>
    Build `web/src/engine/audio/AudioReactivityEngine.ts` per D-11, D-12, D-14, and FX-05.
    - Implement `AudioReactivityEngine` class:
      - Private `freqData = new Uint8Array(128)`.
      - Private smoothed energies: `smoothedBass = 0`, `smoothedMid = 0`, `smoothedTreble = 0`.
      - Configurable parameters:
        - `sensitivity`: number, default 1.0.
        - `attackMs`: number, default 20.0 (fast attack).
        - `releaseMs`: number, default 200.0 (musical release).
        - Optional per-band sensitivity and smoothing overrides.
      - Implement `update(analyser: AnalyserNode, deltaMs: number): { bass: number, mid: number, treble: number }`:
        - Invoke `analyser.getByteFrequencyData(this.freqData)`.
        - Calculate raw energy averages for bass, mid, treble bins.
        - Calculate coefficients: `attackCoeff = 1.0 - Math.exp(-deltaMs / attackMs)`, `releaseCoeff = 1.0 - Math.exp(-deltaMs / releaseMs)`.
        - For each band, if `rawTarget > smoothedCurrent`, use `attackCoeff`; else use `releaseCoeff`.
        - Apply sensitivity, clamp to `[0.0, 1.0]`, and return normalized band values.
    In `web/src/tests/audioEngine.test.ts`:
    - Add tests asserting that a sudden step-up in raw FFT energy takes ~20ms to reach ~63% target (attack), and sudden step-down decays over ~200ms (release).
    - Verify that band energy clamps to 1.0 even with sensitivity = 3.0.
  </action>
  <reversibility rating="reversible">Filter coefficients and bin boundaries are mathematical tuning parameters.</reversibility>
