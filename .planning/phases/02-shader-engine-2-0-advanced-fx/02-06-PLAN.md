      - Point size: calculated based on distance from camera `size.div(depth)`.
      - Shading: Key directional light vector `normalize(vec3(1.0, 1.5, 2.0))` + Rim light `pow(1.0 - dot(normal, viewDir), rimExponent)` (D-18).
