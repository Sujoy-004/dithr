<objective>
Implement client GPU capability detection, adaptive quality tiers, and intelligent idle render scheduling per D-08, RELY-09, and RELY-10.
Detect client WebGPU/WebGL2 limits and device memory to classify performance into High (1080p, 60fps), Medium (720p, 30fps), or Low (480p, 30fps) tiers, allowing explicit manual override via Viewport HUD and Header.
Halt canvas render loops and audio polling via `visibilitychange` and `contentvisibilityautostatechange` when the stage is hidden or off-screen, conserving CPU, GPU VRAM, and device battery while maintaining <16ms wake latency.

Purpose: Eliminate battery drain and GPU overheating during tab backgrounding, and ensure smooth rendering across high-end desktops and resource-constrained mobile hardware.
Output: Capability probing module `web/src/engine/capabilities.ts`, Zustand tier actions in `useStudioStore.ts`, HUD tier badge in `ViewportHUD.tsx` and `Header.tsx`, and adaptive RAF scheduler in `CenterStage.tsx`.

  <name>Task 1: Client GPU capability detection and quality tier classification</name>
  <files>web/src/engine/capabilities.ts, web/src/store/useStudioStore.ts</files>
  <action>
    Create `web/src/engine/capabilities.ts` and integrate with `useStudioStore.ts` per D-08 and RELY-09.
    In `web/src/engine/capabilities.ts`:
    - Define types: `export type QualityTier = 'high' | 'medium' | 'low';` and interface `GpuCapabilities`.
    - Implement `detectGpuCapabilities(): Promise<GpuCapabilities>`.
    - Probe `navigator.gpu`: request adapter, read `adapter.limits.maxTextureDimension2D`. If WebGPU available, texture size >= 8192, `navigator.deviceMemory >= 4`, and not mobile user-agent, classify as `high` tier (`medium` if mobile or smaller texture limits).
    - If WebGPU unavailable, probe WebGL2 on an offscreen canvas: read `gl.getParameter(gl.MAX_TEXTURE_SIZE)`. Classify as `high` (>= 8192 and memory >= 8 and !isMobile), `medium` (>= 4096 and memory >= 4), or `low` (< 4096 or memory < 4).
    In `web/src/store/useStudioStore.ts`:
    - Add state fields: `detectedTier: QualityTier`, `activeTier: QualityTier`, `tierOverride: QualityTier | null`, `gpuEngine: 'webgpu' | 'webgl2'`, `maxTextureSize: number`.
    - Add actions: `setDetectedCapabilities(caps: GpuCapabilities)`, `setTierOverride(tier: QualityTier | null)`.
    - Derive resolution and target FPS from `activeTier`: High -> 1080p, 60 FPS; Medium -> 720p, 30 FPS; Low -> 480p, 30 FPS.
  </action>
