## UI Touchpoint Specifications

### 1. GPU Capability Tier & Render Scheduling (RELY-09, RELY-10)

- **Header / Viewport HUD Tier Badge**:
  - Location: Top Header bar right side and Viewport HUD.
  - Display format: `[TIER: HIGH]`, `[TIER: MED]`, `[TIER: LOW]` along with probe engine `[WEBGPU]` or `[WEBGL2]`.
  - Manual Override Toggle: Clicking the badge opens a lightweight popover with radio items:
    - `● Auto (Detected: High)`
    - `○ High (1080p canvas, full shader passes, 60 FPS)`
    - `○ Medium (720p canvas, optimized passes, 30 FPS)`
    - `○ Low (480p canvas, minimal passes, 30 FPS)`
  - Style: Hairline 1px border (`#222222`), 11px font, `#00ff66` accent when active, `#777777` dim for non-selected options.
- **Render Loop Idle / Pause Feedback (RELY-10)**:
  - Trigger: When document `visibilitychange` fires `hidden` or CenterStage `contentvisibilityautostatechange` fires `hidden`.
  - Behavior: `requestAnimationFrame` and audio polling cancel immediately (0% CPU/GPU usage).
  - Status Indicator: Footer status bar reflects state:
    - Active: `render: active (60fps)`
    - Inactive / Hidden: `render: paused (idle standby)`
  - Re-entry: Immediate resumption on `visibilitychange: visible` (<16ms, zero reload flash).

### 2. Export Cancellation & Progress Feedback (RELY-01, RELY-02)

- **Server Export Progress & Cancellation (RELY-01)**:
  - Location: `ServerExportModal.tsx`.
  - Progress bar: ASCII progress bar `[==========>-------------] 42%` in `#00ff66` accent.
  - Stage indicator: `Stage 2/4: Uploading Stream Chunks (14.2 MB / 34.0 MB)`.
  - Telemetry readouts: Encoding Speed (`1.2x`), Telemetry FPS (`30.0`), Elapsed Time (`00:14`).
  - Cancellation Button: `Cancel Export Job` styled with destructive `#ff4444` border and text.
  - In-flight cancellation state: Clicking button changes label to `Canceling Export Job...` and displays `Terminating FFmpeg subprocess and cleaning job storage...`. Modal closes once cleanup finishes with toast: `Export job canceled. Temporary files purged.`
- **Upload Ingress Security Error States (RELY-02)**:
  - 50MB ceiling rejection (HTTP 413): Displayed in red error banner inside dropzone or modal:
    `File exceeds 50MB limit. Select a shorter clip or compress input media under 50MB.`
  - Magic byte validation failure (HTTP 400): Displayed in modal or dropzone error toast:
    `Unsupported file format. The file header does not match a valid PNG, JPEG, WebM, or MP4 container.`
  - SlowAPI Rate limit (HTTP 429): Displayed in modal warning banner:
    `Audio export rate limit reached (5 req/min). Please wait 60 seconds before initiating a new transcode.`

### 3. Client WebM & GIF Clip Recording (RELY-03, RELY-04)

- **ExportDrawer Clip Panel**:
  - Buttons:
    - `Record WebM Clip` — triggers `recordWebmClip()` with synchronized audio track.
    - `Record Animated GIF` — triggers worker-offloaded `recordGifClip()` with sequential distinct frames.
  - Options:
    - Duration slider: 1s to 10s (WebM) / 1s to 5s (GIF).
    - Audio track toggle: `Preserve Audio Track [x]` (WebM only, enabled by default).
  - Progress feedback:
    - Inline progress indicator: `Recording WebM Clip... 65%`
    - GIF worker progress: `Sampling frames... 40% (12/30 distinct ticks)` -> `Worker encoding GIF... 85% (Quantizing 256 colors...)`
  - Inline Cancellation:
    - `Cancel Recording` button appears beside the progress bar while recording is active.
  - Completion Toast:
    - WebM: `✔ WebM clip downloaded with synchronized audio.`
    - GIF: `✔ Animated GIF downloaded (30 sequential frames).`
