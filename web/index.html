Quick start

Run the terminal player, start the browser studio locally, or launch the FastAPI export service.

  1. 1. Run the Python terminal player

    Requires Python 3.10+ with FFmpeg and FFplay on your path for ANSI True Color video and synced audio. 

    git clone https://github.com/Sujoy-004/ASCII.git
cd ASCII
pip install -e .
rgb-ascii video.mp4 --half-block

  2. 2. Start the browser studio locally

    Requires Node.js 18+ and opens the Vite workspace with the shader rail, canvas preview, tone curve controls, and export drawer. 

    cd web
npm install
npm run dev

  3. 3. Start the FastAPI export service

    Starts the local MP4 and GIF transcoding service on port 8000 for full-duration exports. 

    pip install -r requirements.txt
uvicorn src.api.main:app --host 0.0.0.0 --port 8000 --reload

Privacy and specs

Media loaded in the browser studio stays in local GPU memory unless you explicitly trigger a server export.

Frequently asked questions

Does the browser studio upload my files or camera feed?

No bytes leave your machine during editing or client exports because images, videos, and webcam streams stay inside local GPU textures.

What happens if my browser does not support WebGPU?

The studio switches automatically to Three.js WebGL2 so all sixteen shaders still run on standard browsers without WebGPU.

Why is client GIF recording capped at 1 to 5 seconds?

Browser GIF encoding quantizes uncompressed frames inside tab memory, so capping clips at five seconds prevents tab crashes on desktop and mobile devices.

How does the Python terminal player keep audio in sync?

An FFplay audio clock serves as the master timebase while FFmpeg pipes decoded video frames, allowing the player to drop or hold frames as terminal throughput changes.

When should I run the FastAPI export service?

Run the FastAPI service when you want full-length H.264 MP4 videos with preserved source audio or high-resolution two-pass palette GIFs.
